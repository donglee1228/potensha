# 포텐샤(빠잉)

Windows 도구 소개 · 사용법 · 다운로드 페이지 (다크 마스큘린 테마).

- `index.html` — 단일 파일 페이지 (GitHub Pages 배포용, 내용은 암호화되어 있음)
- 입장 비밀번호 → 홈의 번호 타일 → 타일을 누를 때마다 패널 비밀번호 → 상세 화면(사용법 · 다운로드)

## 패널
1. 레이더: 리니지레이더 — 사용법 · 다운로드 · 익명 댓글 (Release `lineage-radar-v1`)
2. F키반복: F5·F6 중 고른 키 누름 + 좌클릭 반복 도구 (Release `fkey-v1`)
3. 비활성반복: 고른 창 하나에만, 창이 뒤에 있어도 목록에서 고른 키를 반복해 보내는 도구 — 키비활성반복 (Release `bgkey-v2`)
4. 타이머형식매크로: 정한 시간이 지나거나 정한 시각이 되면 고른 창에 키를 1번 누르는 도구, 비활성/활성 모드 (Release `timer-v2`)
5. 보스시간표: 보스 29종 매일 시간표 — 다음 보스·남은 시간, 곧 나올 순서 / 보스별 시간표, 이름 검색 (다운로드 없음)

프로그램은 모두 사용 기간 30일.
